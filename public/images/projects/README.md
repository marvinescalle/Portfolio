# Captures d'écran des projets

Déposez ici les captures, puis renseignez le champ `image` du projet
concerné dans `src/data/projects.js` :

```js
image: "/images/projects/mon-projet.png",
```

Format : PNG ou JPG, environ 1600 px de large, moins de 500 Ko.
Si `image` vaut `null`, une plaque typographique portant le titre du projet
s'affiche à la place.
